# Каталог транспортных маршрутов

Пакет `src` содержит модель транспортного маршрута, каталог объектов и функции
сохранения и загрузки JSON. Маршруты хранятся в словаре с индексом по строковому ID.

**Реализованные операции**:

* Добавление, получение и удаление маршрутов по ID.
* Поиск по категории и полному имени.
* Получение количества маршрутов, итерация и проверка наличия ID.
* Сохранение всех полей в JSON и атомарная загрузка каталога.

**Пользование**:

```python
from src.catalog import RouteCatalog
from src.models import Route

catalog = RouteCatalog()
catalog.add(Route("10", "Центральный", "Автобус", 2000, "Вокзал", "Парк", 12.5))
print(catalog.get("10"))
```

## Модель маршрута

`Route` — неизменяемый `dataclass` с проверкой полей при создании.

| Поле | Тип | Ограничения |
| --- | --- | --- |
| `route_id` | `str` | Непустая строка; уникальность проверяется при добавлении в каталог |
| `name` | `str` | Непустая строка |
| `category` | `str` | Непустая строка, например `Автобус` или `Трамвай` |
| `launch_year` | `int` | Положительное целое число; `bool` не допускается |
| `start` | `str` | Непустая строка, начальная остановка |
| `end` | `str` | Непустая строка, конечная остановка |
| `distance_km` | `float` | Положительное конечное число; передаётся как `12.5` или `12.0` |

Строки из одних пробельных символов отклоняются. Значения строк не обрезаются
и сохраняются в исходном виде. Начальная и конечная остановки могут совпадать.
Метод `Route.from_dict(data)` создаёт маршрут из словаря полей.

## Каталог

`RouteCatalog()` создаёт пустой каталог.

| Операция | Результат |
| --- | --- |
| `add(route)` | Добавить маршрут; повторный ID запрещён |
| `get(item_id)` | Получить маршрут по ID |
| `remove(item_id)` | Удалить маршрут по ID |
| `find_by_category(category)` | Вернуть кортеж маршрутов с точно совпадающей категорией |
| `find_by_name(name)` | Вернуть кортеж маршрутов с полным совпадением имени без учёта регистра |
| `len(catalog)` | Получить количество маршрутов |
| `iter(catalog)` | Получить итератор маршрутов |
| `item_id in catalog` | Проверить наличие ID |

Пустая категория или пустое имя возвращают все маршруты. Поиск имени использует
`casefold()`. Поиск подстроки не выполняется. Результаты поиска представлены
отдельными кортежами и не позволяют изменять внутреннее хранилище.

Итерация и результаты поиска сохраняют порядок добавления. После удаления
и повторного добавления маршрут помещается в конец.

Получение по ID, добавление, удаление и проверка наличия выполняются в среднем
за `O(1)`. Поиск по категории и имени перебирает все маршруты — `O(n)` без учёта
длины строк. Получение количества маршрутов — `O(1)`.

## Сохранение и загрузка

```python
from src.storage import load_catalog, save_catalog

save_catalog(catalog, "routes.json")
load_catalog(catalog, "routes.json")
```

Путь может быть строкой или `pathlib.Path`. Файлы читаются и записываются в UTF-8.
Сохранение перезаписывает существующий файл. Родительская папка должна существовать.

При загрузке проверяются структура документа, версия, поля маршрутов и повторные
ID. Маршруты сначала создаются во временном каталоге. После полной проверки
содержимое переданного каталога заменяется данными файла. Если документ повреждён,
исходный каталог сохраняется без изменений. Порядок записей файла сохраняется.

**Пример `routes.json`**:

```json
{
  "format_version": 1,
  "items": [
    {
      "route_id": "10",
      "name": "Центральный",
      "category": "Автобус",
      "launch_year": 2000,
      "start": "Вокзал",
      "end": "Парк",
      "distance_km": 12.5
    }
  ]
}
```

## Исключения

Все предметные исключения наследуются от `CatalogError`.

| Исключение | Причина |
| --- | --- |
| `InvalidRouteError` | Недопустимые значения полей при создании маршрута |
| `DuplicateIdError` | Добавление маршрута с существующим ID |
| `RouteNotFoundError` | Получение или удаление отсутствующего ID |
| `UnsupportedFormatVersionError` | Неизвестная целочисленная версия формата |
| `CorruptedFileError` | Повреждённый JSON, неверная структура, неверная запись или повторный ID в файле |

Ошибки открытия и записи файлов передаются как стандартные исключения Python.
При прямом вызове `Route.from_dict` пропущенные и лишние поля вызывают `TypeError`;
при загрузке JSON эта ошибка преобразуется в `CorruptedFileError`.

# Установка

Должен быть установлен Python >= 3.12 и uv.
Зависимости указаны в `pyproject.toml`, версии зафиксированы в `uv.lock`.

Перейдите в папку проекта и установите зависимости:

```powershell
git clone https://github.com/Gimid934/lab03.git
cd lab03
uv sync
```

## Запуск

Команда выполняется из корня проекта:

```powershell
uv run python -m samples.main
```

Демонстрация создаёт два маршрута, выводит каталог, выполняет поиск и удаление,
сохраняет JSON и загружает его в новый каталог. Файл `samples/routes.json`
создаётся рядом с демонстрацией и перезаписывается при повторном запуске.

## Тесты и проверки

```powershell
uv run python -m pytest
uv run --with ruff ruff check .
uv run --with mypy mypy .
```

Тесты проверяют инварианты модели, неизменяемость ID, операции каталога,
предметные ошибки, поиск без учёта регистра, пустые запросы, порядок итерации,
независимость результатов поиска, сохранение всех полей и загрузку JSON.
Отдельно проверяются неизвестная версия, повреждённый документ и сохранение
исходного состояния при ошибке записи в середине файла.
